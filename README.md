## Overview

Fallout New Vegas JSawyer Ultimate Config provides a graphical interface for configuring JSawyer Ultimate Edition, the comprehensive survival overhaul mod. It exposes the mod's survival mechanics toggles, carry weight adjustments, karma system tweaks, and hardcore mode parameters as readable GUI controls rather than INI file entries.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Fallout New Vegas JSawyer Ultimate Config** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Survival Toggles** | Enable or disable individual survival mechanics independently |
| **Carry Weight** | Adjust base carry weight and SPECIAL stat carry weight multipliers |
| **Karma System** | Configure karma thresholds and reaction triggers for NPCs |
| **Hardcore Params** | Tune food/water/sleep drain rates for hardcore mode intensity |
